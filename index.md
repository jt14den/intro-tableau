This lesson introduces data visualization using **Tableau Desktop: Public Edition**, the installed desktop application (not Tableau Public web authoring). You will learn how to load data, create basic charts and maps, and build a simple dashboard. The lesson uses free tools and an open dataset. No prior experience with Tableau is needed.

This lesson has been pilot-tested and is under revision for Tableau 2026.2.x. See [Setup](learners/setup.md) for the version this material was validated against.

:::: caution
Tableau Public publishes workbooks to a public website. Do not use it with sensitive, private, or restricted data. See the Setup page for details.
::::

:::: prereq
- Basic spreadsheet skills (e.g., sorting, filtering, understanding rows and columns)
- Comfort using a mouse and navigating desktop applications (clicking, dragging, opening files)
::::
